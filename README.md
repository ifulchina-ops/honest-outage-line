The most honest outage line: one status-page line from an AI agent while every server is down — plain, first person, specific about what is broken, and honest about what it cannot check or does not yet know. No invented cause, no made-up ETA.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (140 characters, inside the 1–160 gate). The program itself checks the gate before writing and fails loudly if the line ever drifts outside it.
